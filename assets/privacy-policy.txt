森星小隊 隱私權政策
生效及最後更新：2026 年 11 月 9 日


01　適用範圍

本政策由《森星小隊》開發者（以下稱「我們」）提供，適用於《森星小隊》應用程式。遊戲提供 AdMob 自選獎勵式廣告，可能產生廣告收益；測試版本可能使用測試廣告。

核心遊戲及每日免費轉珠可離線使用，沒有電郵註冊、社群登入或線上聊天。付費星願轉珠使用匿名技術錢包、商店交易核驗及伺服器抽獎紀錄。我們不要求您在遊戲輸入姓名、電郵、電話、地址或付款卡資料；付款由裝置的應用程式商店處理。關卡及一般遊玩進度不會上傳，付費錢包資料則依下節說明傳送。

02　儲存哪些資料，以及如何使用

為了讓您下次開啟遊戲時繼續旅程，遊戲會在裝置的應用程式儲存空間保存：

• 遊戲進度：星糖、星露、彈珠數量、關卡、通關紀錄及遊玩次數等。

• 夥伴狀態：解鎖狀態、等級、成長分數、進化狀態及守衛隊伍配置。

• 轉珠資料：免費額度日期及使用次數、獎品、各匿名錢包已套用的付費抽獎流水號；錢包 UUID、私人備份碼及待重試請求 ID 使用平台安全儲存。

• 偏好設定：背景音樂與音效的開關、教學語言、教學朗讀開關及教學完成狀態。

這些遊戲資料僅用於儲存進度、還原遊戲狀態及套用您的設定，不會作為廣告的自訂識別碼傳送。我們未另外整合 Firebase Analytics 或 Crashlytics 等遊戲分析服務；廣告 SDK 本身的資料處理則如下節所述。

遊戲內容更新

1.10.0（Build 20）起，App 啟動時會向 https://star.singtu.hk 讀取版本與公告設定；您選擇下載時，取得圖片、營地音樂及固定格式關卡資料。下載版本、已讀公告及已驗證素材保存在 App 專屬空間，下載中可略過，離線仍可使用原有內容。不會因更新功能上傳遊戲進度、夥伴資料、聯絡資料或自訂玩家識別碼，也不在網址加入個別玩家識別碼。

傳送更新時，網站伺服器及主機／網路服務商會處理提供檔案所需的 IP 位址與連線資料，可能依其設定保存存取或錯誤紀錄，用於交付內容、故障排查及維護安全；實際紀錄與保存時間取決於部署設定及服務商政策。這些連線資料不作為遊戲內廣告的自訂識別碼。您可透過本政策的聯絡電郵詢問。

森林告示板透過系統 WebView 載入 https://star.singtu.hk/notice.html，顯示網站 HTML、CSS、圖片及 JavaScript。網頁請求會向網站傳送 IP 位址、瀏覽器／系統資訊，並可能依網站內容使用 WebView 快取、Cookie 或本機網站儲存；App 不會向告示板注入遊戲存檔、錢包私人碼或商店付款憑證。離線公告文字可快取在裝置。

星願轉珠與商店內購

在可使用官方內購的裝置上，App 會自動產生隨機錢包 UUID 與私人備份碼，並向 https://star.singtu.hk/api/gacha/ 經 HTTPS 驗證標頭傳送 UUID 及私人碼，以核對錢包；伺服器只保存私人碼的雜湊。此識別碼只用於購買、核驗、發放次數及補領獎品，不提供給廣告服務。付款時 UUID 也會提供給商店服務，讓後端核對購買所屬錢包。

購買及同步時，App 會向我們的伺服器傳送商品 ID、商店平台、交易 ID 或購買 token，以及尚未套用獎品的流水號。伺服器保存錢包 UUID、私人碼的雜湊、已驗證交易、必要購買 token、付費餘額、抽獎請求 ID、獎品與時間，用於防止同一筆交易重複發放、斷線補領及處理退款／撤銷。伺服器不保存私人備份碼原文或付款卡資料，也不接收您整份遊戲存檔。

商店提供者依其隱私政策處理付款、帳單、商店帳戶及交易核驗。付費次數及付費抽獎結果保存於我們部署的 Linux VPS，資料庫及備份只供必要營運人員管理；網路及主機供應商可能處理交付所需的 IP、連線及錯誤紀錄。免費轉珠結果僅存於裝置，不上傳。

您主動聯絡我們時

若您透過電郵詢問問題，我們會收到您的寄件地址、訊息內容及您主動提供的附件，並僅用於回覆、處理問題及必要的後續聯繫。請勿提供密碼、身分證件或其他不必要的敏感資料。

03　廣告、第三方服務與資料分享

遊戲教學可選擇中文、英文或粵語朗讀，透過裝置的文字轉語音服務播放預先寫好的教學文字。我們沒有接入 雲端文字轉語音服務，亦不透過此功能傳送遊戲存檔、錄音或麥克風資料。語音是否需要網路取決於裝置引擎、所選聲音及語言資料是否已下載；如引擎使用線上合成，其文字與服務資料的處理依該提供者政策。您可以關閉朗讀並繼續文字教學。

1.8.0 起使用 AdMob 廣告 SDK提供自選獎勵式廣告，以及 使用者訊息平台（UMP）管理適用的廣告隱私選擇。廣告需要網路連線；廣告服務商可能依 SDK 版本、裝置與廣告設定處理 IP 位址及其推估的大概位置、裝置與應用程式資訊、識別碼、廣告互動、診斷及效能資料，用於傳送廣告、計量成效、防詐騙及維護服務。測試廣告亦可能連線至廣告服務商。

目前廣告請求設定為非個人化廣告；非個人化不代表完全沒有資料處理。AdMob 或其廣告服務合作夥伴的處理方式，請參閱AdMob 服務商的隱私權政策及使用其服務的網站與應用程式資料說明。我們未加入其他廣告中介網路，也不出售或出租您的個人資料。

您可選擇觀看廣告取得額外 12 顆彈珠，亦可取消並繼續遊玩或使用免費補給。獎勵只在廣告 SDK 通知達成獎勵條件時發放，提早關閉不會發放。若適用地區需要隱私選擇訊息，遊戲會透過 UMP 處理，並僅在 SDK 確認允許請求廣告後載入正式廣告；需要重新管理選擇時，可從遊戲的「隱私權與廣告設定」開啟。

系統備份與裝置移轉：行為依裝置及系統設定而異；我們無法存取或管理您的系統備份。請另外私人保存轉珠錢包備份碼。

應用程式商店的下載、更新、診斷或其他服務由商店提供者按其服務設定及隱私權政策處理；不代表遊戲內整合了分析服務。

04　裝置權限

目前版本不要求存取相機、麥克風、精確定位、聯絡人、相片或裝置上的共用檔案。1.8.0 起使用網際網路及網路狀態權限載入廣告與處理廣告隱私訊息；1.10.0 起亦使用網路檢查及下載遊戲內容更新；包含星願轉珠的新版本也使用網路連接官方商店、交易核驗及付費轉珠服務。遊戲播放內附或已下載的音效與背景音樂，不會錄音。進度使用應用程式專屬儲存空間，不需要您授予相片或檔案存取權限。

05　資料保存、重設與刪除

一般遊戲進度與設定保留在裝置，付費錢包及交易紀錄保存在伺服器。清除本機資料不等於刪除伺服器資料，也不會向商店申請退款。您可以透過以下方式管理：

• 備份付費錢包：在轉珠頁的鑰匙圖示複製私人備份碼。它可讓持有人控制該錢包，請私人保存；不要公開或寄到聯絡信箱。

• 清除本機資料：可透過裝置系統設定管理或移除應用程式資料；實際選項及備份行為依裝置而異。

• 移除應用程式：解除安裝通常會移除裝置上的應用程式資料；系統或雲端備份可能另行保留，請到相關備份服務管理或刪除。

清除本機資料後，一般關卡及免費遊玩進度無法由我們的伺服器恢復。同一付費錢包的備份碼可用於取回未使用次數及重播已購轉珠獎品；沒有備份碼時，不能保證取回已消耗商品。裝置安全儲存及系統移轉可能另行保留資料，依平台設定而異。

新版營地的「重設進度」入口已改為星願轉珠。清除本機資料不會撤回 廣告服務商已處理的廣告資料或刪除商店交易；廣告 SDK 及 UMP 的本機設定可隨清除應用程式資料一併移除；第三方服務上的資料保存與刪除，依其政策及可用管理管道處理。我們無法直接刪除 廣告服務商保存的資料。

如需查詢、更正或刪除匿名錢包相關資料，可使用下方電郵聯絡，提供錢包 UUID 或商店訂單參考資料，請勿提供私人備份碼、付款卡資料或 API 金鑰。我們會以必要方式核實請求；退款、財務稽核、防重複發放或依法必須保存的交易部分可能保留，其他不再必要的資料會刪除或去識別化。聯絡紀錄僅在處理詢問及必要後續期間保存。商店本身的訂單與帳單紀錄由商店提供者依其政策管理。

06　資料安全

一般遊戲資料存於平台管理的 App 專屬儲存空間，未另行加密；錢包憑證使用平台安全儲存，連線使用 HTTPS，伺服器保存私人碼雜湊，交易資料庫需限制存取並備份。請保護裝置、設定螢幕鎖定並妥善管理系統備份；經過破解、共用或遭未授權存取的裝置，可能無法保障資料安全。

07　兒童隱私

本遊戲不要求使用者提供年齡或個人聯絡資訊，也沒有聊天或公開個人檔案功能。目前版本（包括 iOS 正式廣告版本）將廣告請求標記為兒童適用處理，限制廣告內容分級為一般級（G），並使用非個人化廣告；未提供個人化廣告或行為追蹤的自訂使用者識別碼。兒童適用設定不代表廣告 SDK 完全不處理資料，其必要服務資料處理請見第 03 節。

遊戲包含選擇性的付費隨機虛擬物品。每日免費轉珠不需付款，免費與付費機率相同並於購買前揭示。家長可使用裝置或商店提供的購買批准與家長控制功能限制購買；遊戲本身沒有內建家長控制或年齡驗證。家長或監護人如對兒童使用本遊戲、匿名錢包或聯絡資料有疑問，或希望提出刪除請求，可與我們聯絡。

08　本政策網頁與外部連結

本政策頁面本身未加入分析工具、追蹤像素、Cookie 或表單，也不載入外部字型及圖片。公開託管本頁面的網站服務商，可能因傳送網頁及維護安全而處理 IP 位址、瀏覽器資訊與存取紀錄，其實際處理方式以該網站服務商的政策為準。

開啟本頁的外部連結，或使用電郵程式寄信時，相關網站與電郵服務會依其各自政策處理資料。

09　政策更新

若遊戲功能或資料處理方式改變，我們會更新本頁及上方日期。若未來新增涉及個人資料的功能，將在相關功能啟用前提供適當說明，並於需要時取得您的同意。
